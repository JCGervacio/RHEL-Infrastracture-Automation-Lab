- Goal: learning Ansible in parallel with Bash (see the separate `bash/` learning track), aiming for a SysAdmin/Infrastructure/Cloud Engineer role. This `lab/` directory is a real working Ansible project (playbooks/roles/inventory), not a lesson-page repo like `bash/` — learning here happens by extending real roles, not reading prewritten lessons.
- Current focus (as of 2026-08-01): Jinja2 templates — variables, loops, and conditionals.
